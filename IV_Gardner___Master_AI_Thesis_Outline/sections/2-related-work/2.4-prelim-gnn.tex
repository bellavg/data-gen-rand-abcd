\subsection{Graph Neural Networks}
\label{sec:prelim:gnn}

\subsubsection{Message Passing Framework}
\label{sec:prelim:gnn:mp}
A GNN computes a representation $h_v^{l} \in \mathbb{R}^{w}$ for
every node $v$ by repeated neighbourhood aggregation
\citep{kipf2017gcn,hamilton2017graphsage}. Writing $\mathcal{N}(v)$ for the neighbours of
$v$ and $e_{uv}$ for the attribute of edge $(u, v)$, one layer computes
\begin{equation}
    h_v^{l} = \phi^{l}\!\left( h_v^{l-1},
        \bigoplus_{u \in \mathcal{N}(v)} \psi^{l}\!\left( h_u^{l-1}, e_{uv} \right)
    \right),
    \label{eq:prelim:mp}
\end{equation}
where $\psi^{l}$ builds a message per edge, $\bigoplus$ is a permutation-invariant
aggregation, and $\phi^{l}$ updates the node state. The encoder here is one instantiation
of~\eqref{eq:prelim:mp}, written out in~\ref{sec:method:architecture:equations}.

After $L$ layers, $h_v^{L}$ depends only on the $L$-hop neighbourhood of $v$, a depth-$L$
prefix of the cones of~\eqref{eq:prelim:cone} on an AIG\@. Every depth-coupling argument here,
from the refinement depth of~\ref{sec:method:summary:wl} to hypothesis H1
(\ref{sec:intro:rq3}), rests on this fact.

\subsubsection{Graph-Level Readout and Pooling}
\label{sec:prelim:gnn:readout}
A graph-level prediction pools node representations into one vector, here a mean over
nodes, optionally after summing per-layer outputs so shallow and deep features both reach
the readout (jumping knowledge, \citealp{xu2018jk}). Every node of a graph must be present
in the same forward pass, so a graph is the indivisible unit of batching: batches are
assembled under a node budget rather than a fixed graph count
(\ref{sec:method:experiment:batching}), and the memory cost of one step is set by the
largest graphs, exactly the cost reduction is meant to lower.

\subsubsection{Positional and Structural Encodings}
\label{sec:prelim:gnn:pe}
Message passing sees only relative structure: two nodes with isomorphic $L$-hop
neighbourhoods receive identical representations wherever they sit. A Positional Encoding
(PE) attaches a coordinate to each node to break that indifference. An undirected graph has
no canonical coordinate, so encodings are built from random walks or spectra, but on a DAG
the topological level $\ell(v)$ of~\eqref{eq:prelim:level} is an absolute coordinate the
graph carries for free, making the level-based encoding used here
(\ref{sec:method:data:representation:pe}) DAG-native rather than generic.

\subsubsection{Expressivity and the Weisfeiler-Leman Hierarchy}
\label{sec:prelim:gnn:expressivity}
Colour refinement, equivalently the one-dimensional Weisfeiler-Leman algorithm (1-WL),
iteratively refines a node colouring by the multiset of neighbour colours,
\begin{equation}
    c_v^{(t)} = \operatorname{hash}\!\left( c_v^{(t-1)},\
        \bigl\{\!\!\bigl\{\, c_u^{(t-1)} : u \in \mathcal{N}(v) \,\bigr\}\!\!\bigr\}
    \right),
    \label{eq:prelim:cr}
\end{equation}
from initial labels $c_v^{(0)}$, and run to a fixed point computes the coarsest
\emph{equitable} partition of $\mathcal{V}$ refining it, one where every class's nodes share
a neighbour count in every class \citep{grohe2014colourrefinement}. A message-passing
network is at most as discriminative as 1-WL, so two nodes sharing a colour after $L$
rounds receive identical representations from every $L$-layer encoder \citep{xu2019gin}.

% Colour refinement, equivalently the one-dimensional Weisfeiler-Leman algorithm (1-WL),
% iteratively refines a node colouring by the multiset of neighbour colours,
% starting from initial labels $c_v^{(0)}$. A partition of $\mathcal{V}$ is
% \emph{equitable} when every node of a class has the same number of neighbours in every
% class; run to a fixed point,~\eqref{eq:prelim:cr} computes the coarsest equitable
% partition refining the initial colouring \citep{grohe2014colourrefinement}. The
% connection to~\eqref{eq:prelim:mp} is an upper bound: a message-passing network is at
% most as discriminative as 1-WL, so two nodes sharing a colour after $L$ rounds receive
% identical representations from every $L$-layer encoder \citep{xu2019gin}.

Replacing the multiset by a set yields bisimulation, asking only whether a neighbour colour
exists, not how many. A count cap $c$ interpolates, truncating each multiplicity at $c$:
$c = 1$ is bisimulation and $c = \infty$ is colour refinement \citep{bollen2023exact}.
Merging nodes the network provably cannot distinguish removes no information it could have
used, so quotienting by such a partition is lossless, and since automorphism orbits form an
equitable partition, symmetric structure is always compressible this way, a redundancy AIGs
carry in quantity: an AND gate's two fanins are interchangeable and datapath logic
replicates one bit slice across the word width. How much survives structural hashing is
measured in~\ref{sec:method:summary:wl}.

% interpolates between the two, truncating each multiplicity at $c$: the cap $c = 1$ is

\subsubsection{Training Cost, Memory, and Inference}
\label{sec:prelim:gnn:cost}
Training and inference differ in what memory holds: backpropagation through $L$
applications of~\eqref{eq:prelim:mp} retains every layer's node states and materialised
edge messages, while forward-only inference keeps one layer resident. Above a
graph-independent floor, the memory a graph itself costs is
\begin{equation}
    \begin{aligned}
        \Delta m_{\mathrm{train}} &= \Theta\!\left( L \left(
            \left| \mathcal{V} \right| + \left| \mathcal{E} \right| \right) w \right), \\
        \Delta m_{\mathrm{infer}} &= \Theta\!\left( \left(
            \left| \mathcal{V} \right| + \left| \mathcal{E} \right| \right) w \right),
    \end{aligned}
    \label{eq:prelim:memory}
\end{equation}
and the factor $L$ between them is the whole asymmetry, with the largest graph in the
corpus setting the peak, since pooling forbids splitting a graph across steps
(\ref{sec:prelim:gnn:readout}).

This factor $L$ is the mechanism RQ5 (\ref{sec:intro:rq5}) depends on: training on $R(G)$
and querying on $G$ stay inside one memory budget when
\begin{equation}
    \left| \mathcal{V}(G) \right| + \left| \mathcal{E}(G) \right|
    \;\leq\; L \left( \left| \mathcal{V}(R(G)) \right|
        + \left| \mathcal{E}(R(G)) \right| \right),
    \label{eq:prelim:crossstate-budget}
\end{equation}
so any reduction retaining more than a $1/L$ share of $G$ admits full-graph inference on
the hardware its own training required, making training the binding constraint.

Four techniques recur in Chapter 3, defined here once. Reported memory is
\emph{allocated}, the tensors actually held, not the larger \emph{reserved} pool the
allocator keeps (\ref{sec:method:experiment:metrics:efficiency}). Mixed precision halves
activation cost by storing them in half-width floating point. Gradient checkpointing
discards and recomputes intermediate activations on the backward pass, trading compute for
memory and making the largest baseline runnable at all
(\ref{sec:method:architecture:baselines}). Gradient accumulation sums gradients over
several small steps so the effective batch size exceeds what fits in one. All four trade
against a \emph{fixed} input size, unlike the input reduction this thesis studies
(\ref{sec:relwork:scaling:memory}).

Depth has a cost of its own: a fixed-width representation cannot carry a receptive field
that grows exponentially with it, so distant signal is compressed away, a failure known as
over-squashing \citep{alon2021oversquashing}. Contracting paths shortens the distance
signal must travel, a recognised remedy \citep{dwivedi2022lrgb} and the mechanism behind
hypothesis H1 (\ref{sec:intro:rq3}), which sparsification alone cannot supply.
