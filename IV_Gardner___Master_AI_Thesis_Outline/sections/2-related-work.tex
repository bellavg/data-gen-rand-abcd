% The densest definitions section in the thesis. Chapter 3 uses all of the following and

%   - LEVEL / topological depth: longest path from any primary input. The positional
%     encoding is built from it, level slicing partitions on it, span-weighted METIS
%     weights edges by differences in it, and cone coarsening bands on it.
%   - CAUSAL / LOGIC CONE and LONGEST PATH: used by the whole "generic reduction severs

%     fanout cone reconverges -- is the meaningful one, and is what
