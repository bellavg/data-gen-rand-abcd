\subsection{Baselines for Optimizability Prediction}
\label{sec:method:architecture:baselines}
RQ1 is a comparative claim and needs a reference. Two groups supply one: trivial predictors,
which fix what a given $R^2$ is worth on this label, and three published circuit models
ported to this task.

\subsubsection{Trivial Predictors}
\label{sec:method:baselines:trivial}
Three predictors, fitted on validation and scored on test, so every baseline is scored on
unseen data. Two are constant,
\begin{equation}
    \hat{y}^{\text{mean}}_i = \bar{y}_{\text{val}},
    \qquad
    \hat{y}^{\text{med}}_i = \operatorname{med}\!\left( y_{\text{val}} \right),
    \label{eq:method:baseline-constant}
\end{equation}
and the third is an ordinary least squares fit on graph size alone,
\begin{equation}
    \hat{y}^{\text{size}}_i = \operatorname{clip}_{[0,1]}\!\left(
        \beta_0
        + \beta_1 \log_{10} \left| \mathcal{V}(G_i) \right|
        + \beta_2 \log_{10} \left| \mathcal{E}(G_i) \right| \right).
    \label{eq:method:baseline-size}
\end{equation}
Equation~\eqref{eq:method:baseline-constant} fixes the zero point of~\eqref{eq:method:r2}:
the test mean is the least-squares optimum, so any other constant scores $R^2 \leq 0$, and
the median lower-bounds absolute error likewise. Equation~\eqref{eq:method:baseline-size} is
the weakest non-trivial hypothesis, optimizability as a function of size alone, which any
structural claim has to clear.

\paragraph{Random-encoder control.}
A fourth reference point is architectural, not statistical: the edge-aware encoder of
\ref{sec:method:architecture} at initialisation, with only the regression
head~\eqref{eq:method:readout} trained. Randomly initialised graph convolutions are known
to encode usable structure untrained \citep{gallicchio2020fastdeep}, isolating architectural
bias from learning.
% Original: A fourth reference point is architectural rather than statistical: the edge-aware encoder of
% \ref{sec:method:architecture} with its message-passing weights left at initialisation and
% only the regression head of~\eqref{eq:method:readout} trained. Randomly initialised graph
% convolutions of this kind are known to encode usable structure without training the
% convolution itself \citep{gallicchio2020fastdeep}. Comparing a trained encoder against this
% frozen control isolates how much of a score is owed to architectural inductive bias rather
% than to learning.

Every score reported for these baselines carries the $95\%$ bootstrap interval
of~\ref{sec:method:experiment:metrics:stats}.

\subsubsection{Adapting Published Circuit Models}
\label{sec:method:baselines:published}
SynthNet \citep{chowdhury2021openabc}, HOGA \citep{deng2024hoga} and DeepGate4
\citep{deepgate4_2025} are introduced in~\ref{sec:relwork:ml4eda:baselines}. None was
published for this task, so what follows states only the adaptations, not the models.

\paragraph{Shared porting procedure.}
Each paper supplies an encoder $g_\phi$ mapping an AIG to node states
$\{ h_v \}_{v \in \mathcal{V}(G)}$; reusing it unmodified and replacing the head, every port
has the form
\begin{equation}
    \hat{y}(G) = \operatorname{Sigmoid}\!\left(
        \operatorname{MLP}\!\left(
            \pi\!\left( \{ h_v \}_{v \in \mathcal{V}(G)} \right)
        \right) \right),
    \label{eq:method:baseline-port}
\end{equation}
with $\pi$ a permutation-invariant readout and a terminal sigmoid matching the target range
(\ref{sec:prelim:formalization}).

Whether $\pi$ is inherited or chosen differs by model: SynthNet's own concatenated max/mean
pooling already predicts a graph-level quantity; HOGA and DeepGate4 do not, so both instead
use mean pooling, this work's choice.

\paragraph{Adaptations required by a graph-level target.}
Three, each a consequence of the target being one scalar per circuit under one fixed script:

\begin{itemize}
    \item \textbf{The recipe branch is removed.} SynthNet predicts $\hat{y}(G, s)$,
    conditioning on a synthesis recipe $s$ through a separate encoder; with the script fixed
    here, $s$ is constant across the corpus, so the branch would only emit a constant bias
    and is dropped rather than learned.
    \item \textbf{Batches are bounded by nodes, not graphs.} A graph-level readout needs all
    of $\mathcal{V}(G)$ in one pass, so no published batch size transfers; batches are
    assembled instead to a node budget $B$ and accumulation $a$, tuned as a pair so the
    product $a \cdot \mathbb{E}[\,B / |\mathcal{V}(G)|\,]$ stays near the primary model's
    value.
    \item \textbf{Activations are recomputed rather than retained.} DeepGate4's virtual edge
    set $\bar{\mathcal{E}}_k$ (\eqref{eq:relwork:deepgate4}) measures roughly $180$ edges per
    circuit node at radius $k = 8$, against an AIG fanin of at most two; gradient
    checkpointing (\ref{sec:prelim:gnn:cost}) on its attention layers makes the baseline
    runnable.
\end{itemize}

\paragraph{Corrections to the released implementations.}
Two departures correct rather than adapt the released code: HOGA's attention normalises
scores over the head axis instead of the key axis, and its reverse-propagation branch
duplicates the forward branch instead of reversing it; the port fixes both, following Eq.~5.
A third is a convention: OpenABC-D orients edges toward the primary inputs, this corpus the
other way; the port keeps OpenABC-D's orientation and reports that score alone.

\paragraph{Comparability.}
Only the data pipeline is shared; a different split would make the comparison meaningless.
Hyperparameters, optimizer, loss and schedule take each paper's published values, with
settings a paper leaves unpublished recorded as assumptions in~\ref{sec:apx:baselines}.
