The encoder follows GNN+ \citep{luo2024gnnplus}, with hyperparameters from the literature
and the tuning sweep of~\ref{sec:method:experiment:hp}. One architecture serves unreduced,
sparsified, partitioned and summarized graphs, except that partitioning changes the pooling
path (\ref{sec:method:architecture:partitioning}) and the exact-compression track changes
the input schema (\ref{sec:method:architecture:exact}).

The encoder is an edge-aware graph convolutional network: a node carries a one-hot type
indicator over $[\text{constant}, \text{PI}, \text{AND}, \text{PO}]$, an edge a one-hot
inversion indicator. The summarized track's super-node instead counts absorbed members by
role, and its super-edge counts merged inverted and non-inverted wires; a one-hot vector is
the count vector of a single-member super-node, so both graph types share one
four-dimensional input space and encoder weights (\ref{sec:method:summary:schema}). Settings
are in~\ref{tab:method:architecture}, derived in~\ref{sec:method:architecture:equations}.

\subsection{Encoder Formulation}
\label{sec:method:architecture:equations}
The formulation is GNN+'s \citep{luo2024gnnplus}. The classic GCN layer it modifies
\citep{kipf2017gcn} is
% Original: Nothing in this subsection is a contribution of this thesis: the formulation is GNN+'s
% \citep{luo2024gnnplus}, written out in full because the exactness and summarization claims
% of~\ref{sec:method:architecture:summarization} and~\ref{sec:method:architecture:exact} are
% claims about \emph{this} forward pass and cannot be checked against a bulleted
% configuration. The classic GCN layer it modifies \citep{kipf2017gcn} is
\begin{equation}
    h_v^{l} = \sigma\!\left( \sum_{u \in \mathcal{N}(v) \cup \{v\}}
    \frac{1}{\sqrt{\hat{d}_u \hat{d}_v}}\, h_u^{l-1} W^{l} \right).
    \label{eq:method:gcn}
\end{equation}
Throughout, $h_v^{l}$ is the representation of node $v$ after layer $l$, $e_{uv}$ the
attribute of edge $(u,v)$, $\sigma$ the activation, $\|$ concatenation, and biases are
suppressed for readability.

\paragraph{Edge-conditioned messages.}
Each edge attribute is projected by weight $W_e^{l}$ and fused with the neighbour
representation:
\begin{equation}
    m_v^{l} = \sum_{u \in \mathcal{N}(v)}
    c_{uv} \, \sigma\!\left( h_u^{l-1} W^{l} + e_{uv} W_e^{l} \right).
    \label{eq:method:message}
\end{equation}
The per-edge coefficient $c_{uv}$ is~\eqref{eq:method:message}'s one configurable term: the
GCN coefficient $1 / \sqrt{\hat{d}_u \hat{d}_v}$ of~\eqref{eq:method:gcn} under degree
normalisation, or, disabled as here, $1$ with no edge-weight tensor carried.

% representation, so the message a node receives depends on the wire it arrived on:

\paragraph{Normalisation, dropout, residual and feed-forward block.}
GNN+ adds four of its six techniques inside the layer block:
\begin{align}
    \tilde{h}_v^{l} &= h_v^{l-1} + \operatorname{Drop}\!\left( \sigma(m_v^{l}) \right),
    \label{eq:method:residual} \\
    \bar{h}_v^{l} &= \operatorname{Norm}\!\left( \tilde{h}_v^{l} \right),
    \label{eq:method:norm1} \\
    h_v^{l} &= \operatorname{Norm}\!\left( \bar{h}_v^{l}
        + \operatorname{FFN}(\bar{h}_v^{l}) \right),
    \label{eq:method:layer} \\
    \operatorname{FFN}(h) &= \operatorname{Drop}\!\left(
        \operatorname{Drop}\!\left( \sigma(h W_1^{l}) \right) W_2^{l} \right),
    \label{eq:method:ffn}
\end{align}
with $W_1^{l} \colon 128 \rightarrow 256$ and $W_2^{l} \colon 256 \rightarrow 128$. GNN+
additionally normalises the aggregated message before the activation and the residual; that
step is dropped here, leaving only the pre- and post-FFN bracketing of GraphGPS
\citep{rampasek2022graphgps}.
% Original trailing sentence: The two dropouts of~\eqref{eq:method:ffn} follow the GNN+
% reference implementation.

\paragraph{Positional encoding.}
A per-node structural scalar, here the log-compressed logic level $\ell_v$, is projected
and concatenated to the node features rather than summed into them:
\begin{equation}
    h_v^{0} = \operatorname{GraphNorm}\!\left(
        x_v W_{\text{in}} \;\big\|\; \sigma(\ell_v W_{\text{PE}}) \right),
    \label{eq:method:input}
\end{equation}
with $x_v \in \mathbb{R}^{4}$, $W_{\text{in}} \colon 4 \rightarrow 128$ and
$W_{\text{PE}} \colon 1 \rightarrow 32$, so $h_v^{0} \in \mathbb{R}^{160}$: kept whole,
rather than projected back to model width as in GNN+, so the first layer maps
$160 \rightarrow 128$ and alone skips the residual~\eqref{eq:method:residual}.
% Original: with $x_v \in \mathbb{R}^{4}$, $W_{\text{in}} \colon 4 \rightarrow 128$ and
% $W_{\text{PE}} \colon 1 \rightarrow 32$, so $h_v^{0} \in \mathbb{R}^{160}$. GNN+ instead
% projects the joined vector back down to the model width. Keeping all $160$ dimensions
% here means the first layer maps $160 \rightarrow 128$ and is the one layer whose residual
% in~\eqref{eq:method:residual} is skipped, its input and output widths being unequal.

\paragraph{Configuration specific to this work.}
The encoder is GNN+; the following are this project's configuration of it:
\begin{itemize}
    \item \textbf{Degree normalisation off.} $c_{uv} = 1$ in~\eqref{eq:method:message}:
    AIG fan-in is fixed by node type, so the coefficient of~\eqref{eq:method:gcn} would be
    constant within a type pair and adds nothing the type indicator lacks.
    \item \textbf{No self-loop.} Aggregation runs over $\mathcal{N}(v)$ without
    $\cup \{v\}$; a node's own state re-enters only through the
    residual~\eqref{eq:method:residual}.
    \item \textbf{\texttt{LeakyReLU}} for $\sigma$, graph-mode layer normalisation for
    $\operatorname{Norm}$, in place of GNN+'s batch normalisation.
    \item \textbf{Level-based positional encoding}~\eqref{eq:method:input}: log logic
    depth, in place of GNN+'s costlier Random Walk Structural Encoding (RWSE).
    \item \textbf{Readout and head.} Layer outputs summed (jumping knowledge, $L = 4$),
    mean-pooled, through a bounded head, rather than GNN+'s last-layer readout:
\end{itemize}

\subsection{Partitioned Inputs}
\label{sec:method:architecture:partitioning}
Partitioning is the one reduction family that requires an architectural change: edges
spanning partitions are removed offline, disconnecting the graph into $k$ components while
the node set stays intact, so the readout is made hierarchical:

\begin{itemize}
  \item GNN encoder (applied on intra-partition edges only)
  \item Mean pooling from node representations to partition representations
  \item Mean pooling from partition representations to a single graph representation
  \item Prediction head applied to the graph representation to produce the output $\hat{y}$
\end{itemize}

% partitioned offline and the edges spanning partitions are removed, which leaves the node
% set intact but disconnects the graph into $k$ components. Pooling directly to the graph
% level would then average over components the encoder never allowed to communicate, so the
% readout is made hierarchical:

Feature normalization is partition-aware too: \texttt{GraphNorm} normalizes within each
partition rather than within each graph, so statistics do not leak across a boundary
message passing cannot cross.

% within each partition rather than within each graph, so statistics do not leak across a
% boundary the message passing itself cannot cross.

\subsection{Sparsified Inputs}
\label{sec:method:architecture:sparsification}
Sparsification alters only the data pipeline: a sparsified AIG preserves the feature schema
of the original, so the encoder of~\ref{sec:method:architecture} ingests it unmodified.

Reductions are stored as node and edge masks applied at load time, so one corpus serves
every sparsification setting. Edge masks (random edge dropout, spanning forest) leave the
node count unchanged; node masks (PageRank pruning, AND-gate-only) reduce it, so the node
budget governing batch assembly (\ref{sec:method:experiment:batching}) is measured on the
post-mask count.

\subsection{Summarized Inputs}
\label{sec:method:architecture:summarization}
Summarized graphs feed the unmodified encoder because the merge preserves the schema as a
superset (\ref{sec:method:summary:schema}): features become member counts rather than
one-hot indicators, and a single-member super-node reproduces its original row exactly.
Positional encodings pool by member minimum, so a super-node's level is its earliest
member's; this adaptation is untested.

\subsection{Encoder Variant for Exact Colour Refinement}
\label{sec:method:architecture:exact}
Colour refinement at count-cap $\infty$ (\ref{sec:method:summary:wl}) is exact rather than
approximate, but the guarantee holds only under a modified encoder.

When $k$ nodes merge, parallel edges collapse into one super-edge whose message must equal
the sum of the $k$ it replaces. Multiplicity $w_{uv}$ carried as an edge attribute enters
$\sigma$ in~\eqref{eq:method:message}, which does not decompose over sums. Setting $c_{uv}$
to the per-target-member multiplicity $w_{uv} / m_{v}$
of~\eqref{eq:prelim:exact-aggregation} instead scales the message outside $\sigma$ and gives
equality. The divisor is not cosmetic: $w_{uv}$ alone counts member edges across the whole
receiving cluster, whereas the quantity a single node's aggregation needs is the count each
member sees.

Edge attributes are therefore dropped, and inversion moves onto the nodes: fan-in is fixed
by node type (zero for constants and PIs, two for AND gates, one for POs), so a node's type
and inverted-edge count determine which fan-ins are inverted, up to order, which a
graph-level target does not need.
% Original: Edge attributes are therefore dropped, and inversion moves onto the nodes: fan-in is fixed by
% node type in an AIG (zero for constants and primary inputs, two for AND gates, one for
% primary outputs), so a node's type and its count of inverted incoming edges determine which
% fan-ins are inverted, up to order. Which specific fan-in is inverted is lost, which a
% graph-level target does not need.

Coarsening to depth $d = L$ then yields outputs identical
to the uncoarsened graph \citep{bollen2023exact}: the positive control for RQ5
(\ref{sec:method:experiment:design}), traded against schema compatibility, since a full
graph must first be converted, unlike the other methods.
% Original: Coarsening to depth $d$ equal to the number of message-passing layers then yields outputs
% identical to the uncoarsened graph \citep{bollen2023exact}: compression that costs no
% accuracy by construction, and the positive control for RQ5
% (\ref{sec:method:experiment:design}). The variant pays for this in schema compatibility. A
% full graph must be converted before this encoder can be queried on it, whereas the other
% methods support cross-state inference with no such step.

Exactness (\ref{sec:prelim:reduction:exact}) needs two properties from the encoder: a
permutation-invariant sum over the neighbour multiset (\eqref{eq:prelim:exact-aggregation}),
and count-based node features. The former is the multiplicity coefficient $c_{uv} = w_{uv}$
established above. The latter is the summarized schema
of~\ref{sec:method:architecture:summarization}: it keeps the initial colouring able to
separate what the merge already separated, and supplies the member count the weighted
readout needs (\eqref{eq:prelim:exact-readout}).
