\subsection{Partitioning}
\label{sec:method:reduction:partitioning}
Applied to an AIG $G = (\mathcal{V}, \mathcal{E})$, an assignment
$\pi \colon \mathcal{V} \rightarrow \{1, \dots, k\}$ keeps exactly the edges internal to a
block $\mathcal{V}_i = \pi^{-1}(i)$,
\begin{equation}
    R_\pi(G) = \bigl( \mathcal{V},\
    \mathcal{E} \setminus \mathcal{E}_{\mathrm{cut}}(\pi) \bigr),
    \qquad
    \mathcal{E}_{\mathrm{cut}}(\pi)
    = \{\, (u, v) \in \mathcal{E} : \pi(u) \neq \pi(v) \,\},
    \label{eq:method:partition-graph}
\end{equation}
the disjoint union of the $k$ induced subgraphs, so the only quantity a partitioner controls
is the edge retention $\eta_{\mathcal{E}} = 1 - |\mathcal{E}_{\mathrm{cut}}(\pi)| /
|\mathcal{E}|$ of~\eqref{eq:prelim:retention}.

The number of blocks is set per graph from a target block size $s$,
\begin{equation}
    k(G) = \min\Bigl\{ k_{\max},\
    \max\bigl\{ k_{\min},\ \lfloor |\mathcal{V}| / s \rfloor \bigr\} \Bigr\},
    \label{eq:method:partition-k}
\end{equation}
with $s = 10{,}000$ and $[k_{\min}, k_{\max}] = [2, 32]$, fixed by the corpus rather than
chosen: the floor binds below $2s = 20{,}000$ nodes, covering the median graph
(\ref{sec:method:data:statistics:scale}) and guaranteeing every graph is genuinely
partitioned. The cap binds only above $s \, k_{\max} = 320{,}000$ nodes, beyond the largest
evaluation graph, guarding against unbounded $k$ rather than setting an operating point. $s$
was fixed a priori and never swept, leaving its sensitivity unmeasured.

The four methods below receive the same $k(G)$ on every graph and differ only in the
assignment $\pi$, which is what makes them directly comparable.

\subsubsection{Random Hashing}
\label{sec:method:partition:random}
Each node is assigned a block independently and uniformly at random,
$\pi(v) \sim \operatorname{Uniform}\{1, \dots, k\}$, from a fixed seed
(\ref{sec:relwork:reduction:partitioning}), so each edge survives with probability $1/k$,
\begin{equation}
    \mathbb{E}\bigl[ \eta_{\mathcal{E}}(R_\pi(G)) \bigr] = \frac{1}{k},
    \label{eq:method:partition-random}
\end{equation}
independently of the graph. Blocks are balanced only in expectation, but the deviation is
negligible at the block sizes implied by~\eqref{eq:method:partition-k}.

\subsubsection{METIS}
\label{sec:method:partition:metis}
METIS \citep{karypis1997metis} approximates the balanced minimum-cut partition
(\ref{sec:relwork:reduction:partitioning}),
\begin{equation}
    \min_{\pi}\ \bigl| \mathcal{E}_{\mathrm{cut}}(\pi) \bigr|
    \quad \text{subject to} \quad
    \max_{i}\ |\mathcal{V}_i|
    \leq (1 + \varepsilon) \left\lceil \frac{|\mathcal{V}|}{k} \right\rceil,
    \label{eq:method:partition-metis}
\end{equation}
applied unmodified at its default balance tolerance $\varepsilon$: the generic arm of the
comparison, not a method this thesis tuned.

Two consequences matter downstream: edge direction plays no part in where cuts fall
(undirected projection), and every cut edge counts equally, so severing an adjacent-level
connection costs the same as severing an edge spanning half the circuit's depth, the
assumption the domain-informed variant below modifies.

\subsubsection{Level Slicing}
\label{sec:method:partition:levelslice}
Nodes are ordered by topological level~\eqref{eq:prelim:level} and cut into $k$ blocks of
equal cardinality: writing $\operatorname{rank}(v)$ for the position of $v$ in a stable sort
by $\ell(v)$,
\begin{equation}
    \pi(v) = 1 + \left\lfloor
    \frac{k \cdot \operatorname{rank}(v)}{|\mathcal{V}|} \right\rfloor.
    \label{eq:method:partition-slice}
\end{equation}
Balance is exact by construction and blocks are contiguous in depth
($\ell(u) < \ell(v) \Rightarrow \pi(u) \leq \pi(v)$), so an edge is cut only when its
endpoints straddle a block boundary, and local directed structure within each depth band
survives intact. The price: every input-to-output path crosses every boundary and is severed
$k - 1$ times. $k$ comes from~\eqref{eq:method:partition-k}, adding no parameter of its own.

\subsubsection{Span-Weighted METIS}
\label{sec:method:partition:spanmetis}
The domain-aware adaptation changes only the objective of~\eqref{eq:method:partition-metis}:
each edge $e = (u, v)$ has a span
\begin{equation}
    \operatorname{sp}(e) = \ell(v) - \ell(u) \geq 1,
    \qquad
    w(e) = 1 + \gamma \cdot \operatorname{sp}(e),
    \label{eq:method:partition-span}
\end{equation}
the number of levels it crosses, with the weighted cut
$\sum_{e \in \mathcal{E}_{\mathrm{cut}}(\pi)} w(e)$ minimised under the same balance
constraint. A long edge is a shortcut between distant levels. Cutting it removes gates from
the fanin cones~\eqref{eq:prelim:cone} downstream, the damage the uniform objective ignores.
Cut cost under~\eqref{eq:method:partition-span} grows linearly with the chain length broken,
favouring span-one cuts so the longest causal chains stay whole.

The weight $\gamma = 10$ follows from a limit, not a sweep: a minimiser is unchanged by
scaling all weights, so as $\gamma$ grows, $w$ and $\gamma \operatorname{sp}$ pose the same
problem, namely minimising total span severed. Every weight sits within
$1 / (1 + \gamma \operatorname{sp}(e)) \leq 1/11$ of that limit at $\gamma = 10$, so larger
values would move the partition little. Smaller values would not, since at $\gamma = 1$ the
unit term is already half the cost of a span-one cut.
